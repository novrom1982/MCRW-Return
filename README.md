# MCRW-Return

Лёгкий плагин для прокси-сервера **Velocity**, разработанный для проекта **MC Real World** (`mcrealworld.ru`).

Запоминает последний игровой сервер игрока (`survival`, `mini-games` и др.) и автоматически возвращает его туда сразу после успешной авторизации через **AuthMeVelocity**.

## Возможности
- **Независимость от API:** Работает через нативный канал сообщений `authmevelocity:main`, поэтому не ломается при обновлении версий `AuthMeVelocity`.
- **Умный возврат:** Игнорирует сервер лобби (`auth`) при сохранении позиции, чтобы игроки не застревали на спавне авторизации.
- **Поддержка новичков:** При первом входе оставляет игрока в лобби `auth` для выбора режима игры.
- **Нулевая нагрузка на сеть:** Не перехватывает игровые пакеты и не влияет на пинг.

## Требования
- **Velocity:** 3.4.0+ / 4.3.1+
- **Java:** 21+
- **AuthMeVelocity:** 6.0.2+

## Установка и сборка
1. Соберите проект с помощью Maven:
   ```bash
   mvn clean package
   ```
2. Скопируйте `target/MCRW-Return-1.0.0.jar` в папку `plugins/` вашего сервера Velocity.
3. В конфиге `plugins/authmevelocity/config.yml` оставьте `loginServer: ''`.
4. Перезапустите прокси-сервер.
