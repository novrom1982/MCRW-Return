# MCRW-Return

Лёгкий плагин для прокси-сервера **Velocity**, созданный для **MC Real World** (mcrealworld.ru), который автоматически возвращает авторизованного через **AuthMeVelocity** игрока на его последний сервер.

## Возможности

- **Автоматический возврат:** Перенаправляет игрока сразу после прохождения авторизации через сессии `AuthMeVelocity` (`VelocityAuthenticationStore`).
- **Защита от лобби:** Пропускает сервер авторизации (`auth`), позволяя новичкам выбрать режим при первом входе.
- **Управление вручную:** Доступна команда `/mcrwreturn`.
- **Оптимизация:** Работает без перехвата пакетов и нагрузки на сеть.

## Требования

- **Velocity:** 3.4.0+ / 4.3.1+
- **Java:** 21+ (протестировано на Java 27)
- **AuthMeVelocity:** 6.0.2+

## Установка и сборка

1. Соберите проект: `mvn clean package`
2. Перенесите `target/MCRW-Return-1.0.0.jar` в папку `plugins/` на Velocity.
3. В конфиге `plugins/authmevelocity/config.yml` укажите `loginServer: ''`.
4. Перезапустите прокси.
